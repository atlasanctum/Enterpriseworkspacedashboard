## 🆘 Need Help?

**If npm install fails:**
```bash
rm -rf node_modules package-lock.json
npm install
```

**If port 3000 is busy:**
```bash
npm run dev -- -p 3001
```

**If you see errors:**
- Check Node version: `node --version` (need 18+)
- Check terminal for error messages
- Check browser console (F12) for errors
