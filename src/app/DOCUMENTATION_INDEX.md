### Component Structure
```
/components
├── dashboard/        → Dashboard components
├── beneficiaries/    → Beneficiary features
├── fraud/            → Fraud detection
├── analytics/        → Analytics
├── workflows/        → Automation
├── reporting/        → Reports
```

```
/lib
├── actions/          → Server Actions (mutations)
```
